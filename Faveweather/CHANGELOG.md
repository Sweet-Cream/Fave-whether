# Changelog

## 0.3.0 — 2026-11

### Web
- **アセット** タブ（視点の右）：雲の種類を選んで置く／自分で作った雲の形（マイ形）／空いっぱいに雲を敷く／ホワイトボード・写真から雲を作る
- **マイ形**：雲の写真・紙に描いた絵・手描きから、横から見た雲の形を登録して何度でも置ける。ファイルで書き出し・読み込み
- 置いた雲を**回転**・**奥行き**を変更できるように
- **置く** と **描く** を別のボタンに。並びは 置く・描く・動かす・消す・複製
- **天候と雲を完全に分離**：天候は空・光・雨や雪だけを変え、雲の形・高さ・量・カメラには触れない
- 設定に **Blender 用アドオンのダウンロード** を追加
- 書き出し中に画面がちらつく問題を修正

### Blender アドオン
- 雲を作り直し：大小のもこもこを重ねた形を Geometry Nodes でボリュームにし、Mie 散乱で光を計算
- **リアルな描画設定**（下書き／高品質／最高品質）：Cycles・ボリュームバウンス・AgX・デノイズ・GPU
- **360° HDRI を描画**（2K／4K／8K の .exr）
- アプリの **マイ形** を立体の雲として読み込み
